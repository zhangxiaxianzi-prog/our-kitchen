# 两人厨房发布结果

网站地址：https://our-kitchen-oct09.berryokapi.chatgpt.site

项目代码保存在桌面文件夹“/Users/admin/Desktop/两人厨房”。项目内中文文档位于 docs。

## 已完成

- 共同口令登录：相同口令进入同一厨房，不需要 ChatGPT 账号。
- 登录后选择“我”或“女朋友”，允许退出后切换身份。
- 根据图片整理213道初始菜；主要食材按常见做法补充，可以修改。
- 默认一荤两素，手选或随机选菜，每人0到5分，总分至少7分入选。
- 换菜后重新评分；冰箱食材匹配、共享采购清单和菜单管理。
- 菜品支持不再推荐、恢复推荐、永久删除。晚餐记录保留当时内容，最近30轮。

## 验证结果

类型检查、业务规则检查及发布打包均通过。

已在本地与线上真实接口验证：同口令共享、不同口令隔离、两个人同时评分和添加食材保留双方操作、旧候选评分被拒绝、无登录和伪造票据被拒绝、跨站写入被拒绝。

本地浏览器完成登录页及候选菜页检查。后续浏览器复查发生工具超时，因此没有完成所有桌面和手机尺寸的视觉检查，也尚未在用户和女朋友的两部实际手机上验证。

线上检查使用独立口令建立检查厨房，没有使用用户的实际厨房。

## 开始使用

两个人约定8到64个字符的共同口令，分别打开网站输入相同口令，选择各自身份。第一次使用会创建厨房；输错口令会进入另一份厨房，请先核对。

知道口令的人能够选择任一身份并修改厨房数据。请保管口令；初版没有口令找回功能。
