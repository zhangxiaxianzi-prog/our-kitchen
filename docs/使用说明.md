# 两人厨房使用说明

## 两个人怎么进入

1. 约定一个8到64个字符的共同口令，建议是一句只有两个人知道的话。
2. 两个人打开同一个网站，输入完全相同的口令，大小写也要一致。
3. 你选择“我”，女朋友选择“女朋友”。当前手机会记住登录30天。
4. 第一次使用口令会创建厨房。输错口令会打开另一份厨房，而不是原来的厨房；发现菜单或冰箱不对时，退出并核对口令。

共同口令的持有人可以选择任一身份，所以能切换后看到另一人的自己的分数，并在尚未出结果时修改评分。这是用户已确认的简化方式，不能验证现实情侣关系。口令首尾空格会去掉，中间空格保留。

## 日常使用

- 在冰箱页添加已有的主要食材，用完了就移除。小程序中把食材向左滑动，点击移除并确认；右滑或点击食材可收起按钮，也可以用管理模式批量整理。不记录重量和常用调料。
- 今晚吃什么默认搭配一荤两素，可以分别设置荤菜、素菜数量，合计1到6道。调整用于下一轮，本轮数量固定。勾选“只用冰箱已有食材”后，只推荐主要食材已齐的菜。
- 两个人分别给候选菜0到5分。评分期间只显示自己的分数，对方显示是否已评分。都打完后公开分数，合计至少7分才入选；低于7分自动换同类菜，在本轮淘汰记录里保留结果。出结果后不能改分。未评分不是0分。
- “换一道”随机换成另一道同类菜，也可以“自选”。换菜后清空新候选的评分。
- 菜不足时会提示，不会重复凑数。被本轮淘汰的菜不再抽到；补足菜单或食材后可以继续换菜。
- 生成采购清单时，只计算当前晚餐中评分通过的菜，合并缺少的食材，不删除用户手动加的采购项。
- 买到食材后打勾，再点击“把买到的加入冰箱”；这些采购项会从清单中移除。
- 菜单支持新增、编辑、不再推荐、恢复推荐和永久删除。永久删除需确认，已经生成的晚餐记录保留当时菜名、食材及评分。
- 开始新一轮搭配会按当前选择的荤素数量开始新一轮，之前的晚餐保留在历史里。历史保留最近30轮。

## 菜单说明

菜名根据菜单截图整理，重复项合并。食材按常见做法补充，不能当作截图提供的完整配方。含肉的豆腐菜算荤菜，鸡蛋菜归入素菜。你们可以根据实际做法修改食材和分类。

主要食材已齐只表示记下了这些食材，不表示分量足够。鱼香茄子、干煸豆角等有加肉的做法，默认版本未加肉；采用加肉做法时请编辑食材和分类。

## 同步和边界

- 共享数据保存在云端，浏览器只保存登录票据。页面约每8秒刷新一次，修改成功后立即显示。
- 断网或保存失败时页面会提示，不会假装已保存。
- 不同口令的厨房数据互相隔离。每个厨房最多400道菜单、200种冰箱食材、200项采购食材。
- 登录按网络地址限制，每15分钟最多20次尝试。
- 初版不管理食材重量、过期提醒、自动营养计算和完整烹饪步骤。
- 请保管共同口令，网站没有口令找回功能。知道共同口令的人可以查看和修改对应厨房。

## 查看和复用历史晚餐

在晚餐页底部打开“历史晚餐”，可以搜索菜名，并展开查看当时的食材和评分。淘汰菜单独展开，每次查看更多10条。没有都评完的菜仍隐藏对方分数。

“再吃这一顿”只取达到7分的菜，确认后重新评分。只有2道入选就复用2道，不自动补到原数量。菜品删除、停用或限定冰箱时缺食材，会提示重新选择。历史保存的是选菜结果，不代表实际吃过；最多保留最近30轮（含当前轮）。详细规则见[历史晚餐管理说明](历史晚餐管理说明.md)。
