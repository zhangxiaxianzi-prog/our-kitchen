# 微信小程序实现与验证结果

## 本次实现

新增原生微信小程序和微信云托管接入服务，保留现有Sites网站。网站和小程序使用同一组厨房接口，未修改原网站业务代码。用户在交付后授权助手提交本次改动；远程推送及微信发布尚未执行。

已填写AppID、环境ID和服务名。界面包含今晚吃什么、冰箱、采购清单、菜单，身份显示男生和女生。云托管包用于替换springboot-5wzu旧业务；尚未在线替换。

## 已通过的检查

- 5项离线检查通过：评分显示、云托管请求参数、票据失效处理、旧响应不覆盖新数据、退出及后台停止请求、固定接口和请求大小限制、上游失败返回中文提示。
- 微信官方miniprogram-ci 2.1.31的11项质量检查全部通过；静态依赖分析11个文件、10个模块，没有发现依赖错误。这些检查不等同于真机编译。
- 已用独立测试口令，通过本地接入服务连接已发布网站。验证两个入口共用厨房、并发食材添加和双方评分、一荤两素、采购入冰箱、菜单增删与停用恢复、换菜清空分数。没有使用实际厨房口令或修改实际厨房。

## 尚未完成

- 微信云托管部署：浏览器访问控制台被安全检查阻止，无法由助手操作；没有通过其他入口绕过。
- 完整微信编译：官方工具请求servicewechat.com时出现DNS解析失败，未完成代码包编译；不能把质量扫描描述为编译成功。
- 微信开发者工具登录、模拟器界面检查、微信云托管实际网络与权限检查、真机使用、上传、审核、正式发布尚未完成。
- 云托管MySQL未使用，未删除数据库。已有云托管版本未被删除或修改。

## 交付包

微信云托管服务包.zip包含Dockerfile、package.json、server.cjs，上传时构建上下文为压缩包根目录，监听端口8080。

微信小程序项目包.zip包含project.config.json和miniprogram目录；先解压再导入微信开发者工具。具体步骤见[微信小程序部署说明](微信小程序部署说明.md)。
