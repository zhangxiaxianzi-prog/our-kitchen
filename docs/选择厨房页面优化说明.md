# 选择厨房页面优化说明

首屏优先展示“我的厨房”，身份选择缩为男生／女生切换。厨房名称、归属、最近进入时间与进入按钮组成列表，不给每项操作单独占一个大卡片。白底列表与浅灰绿页面区分，深绿只用于主要操作；中文使用系统字体，名称可换行，按钮保证44px点击高度。

创建和加入并排显示，点击才展开对应表单，同一时间只展开一个；切换时保留输入，收起时关闭键盘，加入申请成功后收起表单。没有厨房时显示创建或加入方向。页面保留实际配额、审批和错误提示。

账号工具使用微信原生操作菜单，提供复制账号标识和退出，管理员额外提供扫码登录管理网页。退出须确认。创建者的管理菜单提供加入申请和生成新口令，保留原先的口令失效确认。菜单回调检查页面、登录状态及对应厨房，防止旧菜单操作另一个厨房。

本次复用wx.showActionSheet和原有接口，不增加后端接口，不改变账号权限、名额、审批、口令和评分规则。不自动进入厨房，不按最近时间重新排序厨房，保留后台原有分页。

原有49项离线测试、213道菜单规则检查、类型与语法检查通过。新增一项入口交互检查通过，覆盖表单互斥与草稿保留、仅创建者显示管理菜单、普通账号不显示管理员扫码、页面或账号变化后旧菜单回调失效。入口页的事件处理方法核对通过。
