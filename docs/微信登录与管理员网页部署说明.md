# 微信登录与管理员网页部署说明

## 必须同时更新的部分

本次包含小程序和后台，不能只上传小程序。后台仍部署到springboot-5wzu，构建目录wechat-gateway，端口8080。Dockerfile已包含账号模块、二维码依赖和管理员网页。需要按以下步骤完成配置和两端发布。当前助手只修改源码，没有触发CI/CD、发布或删库。

## 第一次配置

保留现有DB_HOST、DB_PORT、DB_NAME、DB_USER、DB_PASSWORD、KITCHEN_SESSION_SECRET等变量，增加以下配置：

| 变量 | 内容 |
| --- | --- |
| WECHAT_APP_SECRET | 当前小程序的AppSecret，由你在微信公众平台获取并填入云托管，不放到聊天或代码里 |
| WECHAT_APP_ID | 默认wxd3ad251e8ea72453，使用当前小程序时可不额外填写 |
| ADMIN_WEB_ORIGIN | 默认https://springboot-5wzu-325631-12-1311437624.sh.run.tcloudbase.com。换域名时填写新的HTTPS地址，只填域名部分，不带/admin或结尾斜杠 |
| KITCHEN_ADMIN_OPENIDS | 首次管理员在当前小程序里的OpenID，多个账号用英文逗号隔开；可先为空 |

原提议的KITCHEN_CREATOR_WHITELIST_OPENIDS不再使用。名单通过网页改数据库。

先配置AppSecret并发布后台，再上传新小程序。用微信登录，在口令页面点击“复制我的账号标识”，把复制结果填入KITCHEN_ADMIN_OPENIDS后发布一次后台配置。回到小程序刷新厨房列表或重新打开小程序，即可看到“扫描登录管理网页”。首次配置该管理员时会自动加入白名单，之后在网页中增减名单不需要重启。

第一次设置管理员仍需要一次配置发布。日常白名单更新最多60秒生效，不需要改环境变量。管理员与普通白名单用户的区别是：管理员能维护名单；普通白名单用户只能免除创建限制。

## 管理网页访问

打开云托管公网地址加/admin，例如：

https://springboot-5wzu-325631-12-1311437624.sh.run.tcloudbase.com/admin

点击“生成登录二维码”，在小程序中点击“扫描登录管理网页”并扫码。只确认你自己刚打开的网页。二维码两分钟有效，网页会话一小时有效；到期重新扫码。

添加白名单时，让对方登录小程序并复制账号标识。网页填写这个标识和用于辨认的备注。微信号、昵称、手机号、AppID均不能代替OpenID。停用不会删除其已有厨房，最多60秒后恢复普通账号创建限制。

网页需要HTTPS，登录Cookie不会在普通HTTP下发送。PUBLIC网页地址必须与ADMIN_WEB_ORIGIN一致。云托管需要能访问微信固定登录接口api.weixin.qq.com；本次未验证线上出口可达性。

## 首次使用厨房

旧厨房不迁移，原口令入口关闭，旧小程序会要求更新。新小程序先微信登录，再创建厨房；系统生成口令，复制给另一位。对方发送申请后，创建者回到“我的厨房”，打开“加入申请”并同意。

已获准加入的厨房可从列表直接进入，仍允许选择男生或女生，本次未固定评分账号。厨房名称1到40字，普通账号最多创建三个厨房、每天最多创建一个。

厨房列表和申请列表每页20个，可以翻页。名单和修改记录也分页查询。白名单豁免每日及总数量限制，但不豁免短时间大量操作限制。

## 上线核对

1. 后台与小程序均为本次版本；旧/api/login返回410。
2. 微信登录能够复制账号标识，填入管理员配置后可以扫码登录网页。
3. 两个真实微信账号验证申请前不可进入、同意后可进入、普通成员不能审批。
4. 名单新增和停用在60秒后影响创建权限，已创建厨房仍保留。
5. 实际MySQL事务、两个实例并发创建、数据库读取失败、管理网页手机和电脑显示需要在部署环境验证。

本次离线检查不连接生产数据库；没有执行任何旧记录删除。旧数据不被新账号使用，实际清理数据库不属于本次已经完成的动作。旧口令备份工具不能继续登录新入口，需要以后单独调整，不要用旧工具验证新登录。


## 打开小程序时登录与失败排查

此次修改同时涉及小程序和后台。上传小程序代码后，未登录时打开页面会自动弹出确认窗；发布后台后，微信身份核实失败才会产生新的诊断日志。

在云托管运行日志搜索“核实微信身份失败”。ENOTFOUND或EAI_AGAIN表示域名解析失败；网络连接错误查看错误编号；WECHAT_TIMEOUT表示接口请求超过5秒；WECHAT_INVALID_JSON查看HTTP状态和内容类型；WECHAT_REJECTED查看微信数字错误码。不要根据用户端“暂时无法核实微信身份”直接修改密钥或绕过身份校验。需先根据实际日志确定原因，再修正网络或配置。

日志不包含密钥、完整请求地址、登录凭证、微信身份或响应正文。不要把这些内容另外加入日志。已有有效账号不重复确认，取消或失败保留手动登录入口。


## 云托管微信接口证书配置

运行日志中的DEPTH_ZERO_SELF_SIGNED_CERT表示后台连接微信接口时不信任对方提供的自签名证书，请求尚未取得微信HTTP返回。这次日志不能用于判断AppSecret是否正确。

微信云托管的开放接口服务会在容器内生成微信接口证书。运行镜像安装ca-certificates，准备系统更新证书的工具；通过NODE_EXTRA_CA_CERTS=/app/cert/certificate.crt让Node在进程启动时额外加载平台提供的根证书。证书由平台在运行时提供，不从本地复制或提交到GitHub。接口继续使用HTTPS，保留证书校验。

官方说明：https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/guide/weixin/open.html

推送后需确认CI/CD使用新的Dockerfile构建并上线新版本。若控制台已有NODE_EXTRA_CA_CERTS，需确认没有覆盖镜像中的正确路径。无需修改数据库或重新上传小程序前端。

上线后重新点击微信登录。如果仍出现证书错误，需确认平台证书文件存在且运行账号能够读取，并检查开放接口服务配置。禁止设置NODE_TLS_REJECT_UNAUTHORIZED=0或关闭请求的证书校验。成功连接后如出现WECHAT_REJECTED，再根据微信数字错误码处理接口权限或登录配置。

本地没有Docker命令，本次只检查Dockerfile内容、安装步骤与运行账号的先后关系及差异格式；未在本地构建镜像，也未验证线上真实微信登录。
