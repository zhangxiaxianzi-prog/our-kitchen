# 微信小程序手机适配说明

## 已确认的需求

手机上减少顶部留白，让候选菜更早出现；按钮容易点中；小屏文字和操作不挤在一起。编辑菜品和自选菜弹窗需要在键盘出现后继续使用。

## 本次调整

- 保留原有配色和四个入口，缩短登录、晚餐页面的标题与说明，减少卡片间距。
- 操作按钮最小高度为44像素。320像素宽的手机将0到5分排为两行，每行三个；大屏继续一行显示。
- 长菜名和食材允许换行；小屏冰箱食材每行一项，菜单操作按钮自动换行。
- 编辑菜品和自选菜使用底部弹窗。标题、关闭按钮和保存按钮固定，中间内容可以滚动。
- 使用微信输入组件提供的键盘高度，结合当前窗口高度调整弹窗位置。已经被系统缩小的窗口不再重复向上移动。输入或打开弹窗时隐藏底部导航。
- 使用现有微信组件和页面生命周期，没有新增界面依赖。共同口令、两人评分、7分入选、一荤两素和共享接口继续沿用现有规则。

## 验证结果与边界

- 微信开发者工具中检查390像素宽的常规手机和320像素宽的小屏手机。候选菜、菜单按钮和编辑弹窗显示正常；小屏评分分两行。
- 小程序自动测试共4项通过，包括原有评分展示、登录请求、共享数据刷新，以及新增的键盘与窗口尺寸事件顺序测试。
- 新增测试覆盖窗口保持高度、窗口先缩小、键盘先通知、键盘关闭后窗口恢复，以及页面卸载后的事件。
- JavaScript语法和代码空白检查通过。
- 尚未在真实安卓和iPhone设备上验证键盘、系统大字体与横屏效果；模拟器检查不能替代真机检查。

## 使用与发布

修改已保存在桌面的“两人厨房”项目中，开发者工具已显示新布局。本次没有提交或推送GitHub，也没有上传小程序版本。

GitHub的云托管自动发布用于后台服务，不会自动更新微信客户端的小程序页面。需要在开发者工具上传新版本，再设置体验版或提交微信审核；发布前请用两部手机检查编辑菜品时的键盘和保存按钮。
