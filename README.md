# 两人厨房微信小程序

项目包含微信小程序、云托管后台和独立白名单管理员网页。原普通用户网站已取消，旧厨房数据不再迁移。

- `miniprogram`：小程序页面、冰箱、评分和三餐日历。
- `wechat-gateway`：Node.js 22、MySQL 5.7 共享后台。
- `docs`：中文需求、部署和操作说明。旧网站说明属于历史记录，当前登录和发布以《微信登录与管理员网页部署说明》为准。
- `tests`：离线业务检查，使用假数据库，不代表线上验证。

安装根目录和 `wechat-gateway` 的锁定依赖后运行 `npm test`、`npm run typecheck`。

微信开发者工具打开项目根目录；云托管目标目录仍为 `wechat-gateway`，端口8080。

三餐日历仅保存完成双人评分的菜品，长期保存、按日期分页读取。发布时先更新后台，再上传小程序。微信登录新版为新厨房保存独立日历，旧口令厨房不迁移。不会连接旧网站恢复已经移除的数据。

日历历史备份方式见 [三餐日历需求与方案](docs/三餐日历需求与方案.md)。数据库密码和固定登录密钥仅填在微信控制台，不写入代码。

微信登录、厨房审批和60秒白名单缓存的说明见 [微信登录与厨房权限方案](docs/微信登录与厨房权限方案.md)，首次配置及网页地址见 [微信登录与管理员网页部署说明](docs/微信登录与管理员网页部署说明.md)。
